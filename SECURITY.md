# Security policy

AXtory may process prompts, source code, tool output, file paths, credentials, and personal
data. Treat every collected value as untrusted and potentially secret. Do not attach real
session data to public issues.

The default collector is read-only. Any future command that changes Claude Code, Codex, or
another source must first probe capability, display a change plan, record explicit consent,
back up the existing configuration, merge atomically, verify actual behavior, and support
rollback.

Use GitHub private vulnerability reporting when it is enabled for the repository. If it is not
available, open a content-free issue asking the maintainers for a private contact channel. Do not
publish exploit details, personal sessions, or sample secrets in a public issue.
